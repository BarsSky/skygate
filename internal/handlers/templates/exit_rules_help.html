{{t "help.exit_rules_help.api_post_h4"}}

{{t "help.exit_rules_help.api_with_token"}}
curl -X POST -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"rules":[
    {"device_id":5, "exit_node":"node-europe", "target_type":"subnet", "target_value":"10.0.0.0/24", "action":"accept"},
    {"device_id":5, "exit_node":"node-europe", "target_type":"ip",     "target_value":"1.2.3.4",     "action":"accept"},
    {"device_id":5, "exit_node":"node-europe", "target_type":"domain",  "target_value":"rutracker.org", "action":"accept"}
  ]}' \
  {{.BaseURL}}/my/exit-rules/api

{{t "help.exit_rules_help.api_or_cookie"}}
curl -X POST -b skygate_session=TOKEN \
  -H "Content-Type: application/json" \
  -d '{"rules":[...]}' \
  {{.BaseURL}}/my/exit-rules/api

Response: {"added": 3, "duplicates": 0, "errors": []}

For target_type=domain the server auto-resolves the domain to IPs (if DNS answers) and saves each as subnet /32. The domain rule itself stays in the DB for autoupdater.

FieldTypeRequiredDescription
device_idintyes{{t "help.exit_rules_help.api_field_device_id"}}

target_typestringyes"ip", "subnet", or "domain"
target_valuestringyesIP, subnet (10.0.0.0/24), or domain (example.com)
actionstringno"accept" (default) or "deny"
