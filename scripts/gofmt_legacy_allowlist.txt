# gofmt legacy allowlist — TD-21 RATCHET (B337)
#
# WHAT THIS IS. The repo has pre-existing `gofmt` drift in files nobody has
# needed to touch. Renormalising them is a 30k+-line whitespace-only commit that
# would bury any real change and poison `git blame`, so it is deliberately
# deferred (docs/ROADMAP.md TD-21, and the plan in AGENTS.md rule 3). This file
# freezes the set as of the measurement below.
#
# THE RULES THE CONTRACT ENFORCES (scripts/check_b337_gofmt_ratchet.sh):
#   1. every tracked .go file NOT listed here must be gofmt-clean, so any file
#      you create or touch is held to the rule;
#   2. a file listed here that HAS become clean must be REMOVED from this list —
#      the list may only shrink, which is what makes it a ratchet and not an
#      exemption;
#   3. the list may never grow, and its size is asserted against the frozen
#      count below;
#   4. the list is sorted and unique, so a diff to it is reviewable.
#
# HOW TO PAY IT DOWN. Run `gofmt -w <file>` on a batch, then delete those lines
# here and lower the number in the contract. The renormalisation release does
# exactly that for all of them at once.
#
