Идёт обновление панели

Страница вернётся сама, как только панель поднимется — закрывать вкладку не нужно.

прошло: 0 с проверяю каждые 3 с
Дольше минуты? Посмотрите журнал обновления: journalctl -u skygate -u skygate-update --since "-10 min"
Больше трёх минут — обновление, похоже, не завершилось. Журнал: journalctl -u skygate -u skygate-update --since "-30 min"
